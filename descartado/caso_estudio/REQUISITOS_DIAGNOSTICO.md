# REQUISITOS PARA EJECUTAR EL DIAGNÓSTICO (OE1)

Proceso: admisión y matrícula, UTI sede Quito. Se corresponde con la Tabla "Requisitos para ejecutar el diagnóstico" del Cap. 2 (D01–D10).
Regla: no se recoge ningún dato personal. Todo es agregado, anonimizado o sobre procesos y controles. Los informantes se identifican con códigos E01, E02, …

## Orden de ejecución

D01 → D09 → D02 → D05 → D03/D04 → D06 → D07 → D08 → D10. D01 condiciona todo; D03 y D04 deciden si hay gran escala y, con ello, EIPD y DPD obligatorios.

## Conflicto de interés

El autor administra sistemas de la UTI. Si alguno entra en el caso (p. ej., GitLab CE), se declara y solo se usa información que la institución autorice formalmente (Cap. 2, ética e).

## Salidas esperadas del diagnóstico

1. Tabla de madurez por dominio (Cap. 3).
2. Tabla de verificación normativa por bloque (Cap. 3).
3. RAT completo de SP1–SP6 (Cap. 3).
4. Dictamen de gran escala (sí o no, con puntaje del modelo técnico).
5. Lista de escenarios R-01…R-13 confirmados, reformulados o descartados, más los nuevos.
